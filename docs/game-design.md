# Game Design — 3D Sci-Fi Tower Defense (MVP)

## Концепция

Классический tower defense с фиксированным путём (в духе Kingdom Rush) в неоновой sci-fi
стилистике. Враги идут волнами по дороге к базе; игрок строит башни на свободных клетках
рядом с дорогой. Цель — пережить 10 волн.

Платформа: десктоп, мышь. Стек: Vue 3 (Composition API, TS) + Three.js + Vite.

## Карта

- Квадратная сетка **14 × 10** клеток, размер клетки — `CELL_SIZE` мировых единиц.
- Одна карта в MVP.
- Путь задан списком ключевых точек (waypoints) в координатах сетки `(col, row)`;
  клетки между соседними точками — дорога. Отрезки строго горизонтальные/вертикальные.
- Типы клеток: `buildable` (можно строить), `path` (дорога), `base` (база), `blocked` (декор).
- Спавн — на краю карты, в первой точке пути; база — в последней.

Черновик пути (уточняется при реализации):

```
(0,1) → (3,1) → (3,7) → (7,7) → (7,2) → (11,2) → (11,6) → (13,6) [база]
```

## Башни

| Башня | Стоимость | Урон | Скорострельность | Радиус (клеток) | Особенность |
|---|---|---|---|---|---|
| Пулемёт (Pulse Gun) | 50 | 8 | 5 выстр./с | 3 | Быстрые трассеры |
| Ракетница (Rocket Pod) | 100 | 40 | 0.8 выстр./с | 4 | Сплеш-урон, радиус 1.2 клетки |
| Замедляющий луч (Cryo Beam) | 75 | 5 урона/с | непрерывно | 2.5 | Замедление на 40% (действует 1 с после выхода из луча) |

- Башня занимает одну клетку `buildable`.
- Таргетинг: **First**, то есть враг, прошедший по пути дальше всех (из тех, кто в радиусе).
- Улучшение (1 уровень): стоимость 75% от базовой, урон +50%, радиус +15%.
- Продажа: возвращается 70% всех вложенных средств (постройка + улучшение).
- Улучшение и продажа заложены в модель данных и интерфейс, реализуются после базовой стрельбы.

## Враги

| Враг | HP | Скорость (клеток/с) | Награда | Урон базе |
|---|---|---|---|---|
| Дрон (стандартный) | 60 | 1.5 | 5 | 1 |
| Бегун (быстрый) | 35 | 3.0 | 6 | 1 |
| Танк (медленный) | 300 | 0.8 | 20 | 3 |

- Двигаются по waypoints с постоянной скоростью (с учётом замедления).
- Над врагом — полоска HP.
- Прогресс по пути (пройденная дистанция) используется для таргетинга First.

## Экономика и волны

- Старт: **150 кредитов**, **20 жизней** базы.
- Кредиты: награда за убийство + бонус за волну `20 + 5 × номер волны`.
- Волна стартует **кнопкой в HUD**. Между волнами — фаза строительства без ограничения по времени.
- 10 волн. Победа — после уничтожения последнего врага 10-й волны при жизнях > 0.
  Поражение — жизни упали до 0.
- Состав волн описывается данными (тип врага, количество, интервал спавна, задержка группы),
  чтобы баланс правился без изменения кода.

Черновик состава волн:

| Волна | Состав |
|---|---|
| 1 | 8 дронов |
| 2 | 12 дронов |
| 3 | 8 дронов + 6 бегунов |
| 4 | 15 бегунов |
| 5 | 10 дронов + 2 танка |
| 6 | 12 бегунов + 3 танка |
| 7 | 20 дронов + 10 бегунов |
| 8 | 6 танков + 10 бегунов |
| 9 | 25 дронов + 5 танков |
| 10 | 15 бегунов + 15 дронов + 8 танков |

Все числа — стартовые значения для балансировки.

## Состояния игры

```
ready → build ⇄ wave → victory
                  ↘   defeat
```

- `ready`: стартовый экран.
- `build`: фаза строительства, кнопка «Начать волну» активна.
- `wave`: идёт волна, строить можно, кнопка неактивна.
- `victory` / `defeat`: финальные экраны с перезапуском.

## Управление и камера

- Изометрический ракурс, `PerspectiveCamera` с малым углом обзора и `OrbitControls`:
  - ЛКМ: выбор клетки или башни, постройка;
  - ПКМ / перетаскивание средней кнопкой: панорама;
  - колесо: зум;
  - вращение с жёсткими ограничениями: полярный угол в диапазоне примерно 35°–65°,
    зум и панорама ограничены границами карты.
- Наведение на клетку подсвечивает её и показывает радиус выбранной башни (raycast).

## Визуальный стиль

- Только процедурная low-poly геометрия (Box, Cylinder, Sphere, Cone, Torus), без GLTF.
- Тёмная палитра: почти чёрный фон, тёмно-синий металл, неоновые акценты:
  - дорога: холодный голубой;
  - база: бирюзовый;
  - враги: пурпур/красный;
  - выстрелы: цвет башни.
- Светящиеся элементы — `MeshStandardMaterial` с `emissive`, пересветом выше порога bloom.
- Постпроцессинг: `EffectComposer` + `UnrealBloomPass` + `OutputPass`.
- Сетка арены: тонкие светящиеся линии.

## Звук

Вне MVP первого шага. Позже через Web Audio API.

## Архитектура (кратко)

- Вся игровая логика — чистый TypeScript в `src/game/`, без зависимости от Vue.
- Vue отвечает только за HUD и экраны.
- Связь:
  - состояние идёт из игры во Vue через объект `reactive` (store), который пишет только игра;
  - команды идут из Vue в игру через публичные методы `Game`.
- Объекты Three.js никогда не попадают в реактивное состояние.
