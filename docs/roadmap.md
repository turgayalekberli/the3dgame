# Roadmap

## Фаза 1: каркас
- [ ] Удалить механику Stack (Block, Debris, PerfectFlash, Palette, difficulty, старые экраны и HUD)
- [ ] Store: `reactive`-состояние игры, типы, связь `Game` ↔ Vue
- [ ] Данные карты: сетка 14×10, waypoints, типы клеток
- [ ] Арена: пол, светящаяся сетка, дорога, база, точка спавна
- [ ] Изометрическая камера + OrbitControls с ограничениями
- [ ] Свет + bloom (EffectComposer, UnrealBloomPass, OutputPass)
- [ ] HUD: кредиты, жизни, номер волны, кнопка «Начать волну» (пока только меняет состояние)

## Фаза 2: враги и волны
- [ ] Модели трёх врагов из примитивов
- [ ] Движение по waypoints, прогресс пути
- [ ] Полоски HP
- [ ] Данные волн, спавнер
- [ ] Урон базе, жизни, поражение
- [ ] Бонус за волну, переход wave → build, победа после 10-й волны

## Фаза 3: башни и стрельба
- [ ] Raycast по сетке: наведение, подсветка клетки
- [ ] Панель выбора башни в HUD, предпросмотр радиуса
- [ ] Постройка со списанием кредитов, проверка клетки
- [ ] Три башни: модели, поворот к цели, таргетинг First
- [ ] Снаряды: трассеры пулемёта, ракеты со сплешем, непрерывный луч с замедлением
- [ ] Урон, смерть врага, награда

## Фаза 4: улучшение и продажа
- [ ] Выбор построенной башни, панель башни в HUD
- [ ] Улучшение (1 уровень), визуальное отличие
- [ ] Продажа

## Фаза 5: экраны и полировка
- [ ] Стартовый экран, экраны победы и поражения, перезапуск
- [ ] Эффекты: вспышки выстрелов, взрывы, смерть врагов
- [ ] Балансировка 10 волн
- [ ] Ускорение игры ×2 (опционально)

## Фаза 6: звук
- [ ] Web Audio API: выстрелы, взрывы, старт волны, победа и поражение

## Фаза 7: производительность
- [ ] Пулы снарядов и эффектов
- [ ] InstancedMesh для массовых объектов при необходимости
